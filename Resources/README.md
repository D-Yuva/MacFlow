# Application artwork

`AppIcon-source.png` is the 1254 x 1254 source artwork used for the application
icon. It was generated with OpenAI's image tooling and retains its original
C2PA content-provenance manifest. The manifest identifies the generating
service and public certificate chain; it contains no maintainer identity,
prompt, credential, or private key.

`AppIcon.icns` is the packaged multi-resolution macOS icon. `Assets.car`
contains the compiled AppKit asset rendition used by the application. Both are
derived distribution resources, not executable code, and are covered by the
project's MIT License.

When replacing the icon, commit the new source artwork and regenerated binary
resources together. Do not use private screenshots, personal photos, or assets
whose redistribution rights are unclear.
